# Project instructions

## Writing rules

These are the owner's hard rules for all website copy and writing added to this repository.

- Do not use em dashes. Use full stops, commas or separate sentences.
- Use simple language and short, direct explanations.
- Do not use stock explainers such as "the important thing is" or "what I take from it is".
- Avoid wording that sounds generated by AI. Remove filler, inflated claims, repeated slogans and vague praise.
- Do not use slogans made from a list of verbs, such as "Track. Study. Practise." Use a plain heading such as "Apps by sjgoodapps".
- Base the palette on the OneGLP website's dark blue header, teal buttons and white content areas. Do not use the app icon colours as the website palette.
- Describe what each app does with specific, verified facts.
- Use the product name OneGLP and link to https://oneglp.app/.
- Keep the existing support and privacy wording. If you find a content error, ask the owner before changing it.
- Keep the website usable on desktop and mobile.
- Use the shared design rules in style-guide.html and the tokens in assets/site.css.
- Prepare changes on a review branch. Do not merge or publish without the owner's instruction.

## Development

This is a static GitHub Pages site. The published pages are index.html, support.html and privacy.html in the repository root. There is no package install or build step. Use relative paths so the site also works beneath /sjgoodapps/.

GithubSupportPrivacy/ holds older copies. Do not remove them or change their content as part of a visual redesign unless asked.
